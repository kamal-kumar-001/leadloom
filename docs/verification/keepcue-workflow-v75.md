The downloaded CLI, not direct database inserts, created the project material:

- A small resume snapshot containing references and constraints instead of copying every full draft body.

Identical request retries recover the same saved records. Typed launch-copy search returns one bounded summary without a full body. The engine process was stopped and started again, then the CLI retrieved the exact saved snapshot and selected draft. A separate project credential receives404for the KeepCue asset and sees an empty inventory of its own. Browser inventory/history display the same saved project evidence. Credential revocation takes effect immediately.

Final database checks found zero campaign recipients, sender bindings, outbound jobs, mailboxes, captured submissions and visitors. The validation page remained draft. No provider action, account creation, publication, send or spend occurred. The scenario database and local credential-bearing bundle directory were removed after the run, so this test does not leave a production KeepCue project ready for the user to open. Exact recovery across a process restart was proved before teardown.

## Evidence and repeatability

`apps/web/scripts/keepcue-workflow.synthetic.mts` contains the runnable case. It requires explicit `LEADLOOM_SYNTHETIC_KEEPCUE=1` and a restricted local `LEADLOOM_SYNTHETIC_ADMIN_URL`; it refuses password-bearing or non-local admin URLs. Chrome, PostgreSQL16/vector and the existing built runtime are prerequisites. It is not a production migration or data-import command.

The JSON report records IDs, inventory, zero-effect counters and limits, without bearer tokens. Three screenshots show the actual human inventory, history and frozen zero-evidence growth review and were inspected for readable names, draft states, boundaries and project selection. The runtime log records all four completed stages.

No application implementation, dependency manifest or migration changed from v74. The existing compiled source identity remains `a03c2bfe0cb9044455dd74cbc475b9776b669361a8cd20d2bd1aec379a3eef4f`,764included files.
